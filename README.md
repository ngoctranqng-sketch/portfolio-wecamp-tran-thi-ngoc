# Tran Thi Ngoc — NAB WeCamp Portfolio

A responsive one-page portfolio created for my NAB WeCamp application. It presents my early technical projects, transferable professional experience, and current software development learning journey.

## Live website

https://ngoctranqng-sketch.github.io/portfolio-wecamp-tran-thi-ngoc/

## Featured projects

### Property Listing Discovery & Tracking

A locally hosted n8n workflow that retrieves property data from the Zillow Real Estate API through RapidAPI, processes JSON with JavaScript, ranks and categorizes listings, compares them with existing Google Sheets data, and appends new matches.

### AI-Assisted Short-Video Production Pipeline

A customized Remotion workflow for branded vertical explainer videos. The pipeline coordinates Gemini TTS, Groq Whisper word-level timestamps, sourced or generated visuals, React-based compositions, and FFmpeg rendering.

This project began from an existing paid template. My contribution focused on customizing the branding, layouts, graphic components, voice options, visual sourcing, API connections, input structure, and rendering behavior with AI-assisted development. The original paid source is not redistributed in this repository.

## Local preview

No build step is required.

1. Clone or download this repository.
2. Open index.html in a browser, or serve the folder with a local static server.

Example:

    python3 -m http.server 8000

Then visit http://localhost:8000.
